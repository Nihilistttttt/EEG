# UMW TP4056 — 1A 线性锂离子电池充电器

## 1. 描述

TP4056 是一款高性能单节锂离子电池恒流/恒压线性充电器。采用 ESOP8 封装，外围元件少，非常适合便携式产品，适用于 USB 电源和适配器电源供电。

基于内部特殊的 MOSFET 架构和防反向充电电路，TP4056 不需要外部检测电阻和隔离二极管。当外部环境温度过高或在高功率应用中，热反馈可以调节充电电流以降低芯片温度。充电电压固定为 4.2V，充电电流可通过外部电阻设置。当充电电流在达到最终浮充电压后降至设定值的 1/10 时，芯片终止充电周期。

当输入电压断开时，TP4056 进入休眠状态，电池漏电流降至 **1µA** 以下。TP4056 可设置关断模式，此时芯片静态电流降至 **35µA**。

TP4056 还包含电池温度监测、欠压锁定、自动再充电和两个状态指示引脚。

## 11. 使用说明

TP4056 是专为锂离子电池设计的线性充电器。它使用芯片内部的功率 MOSFET 以恒流/恒压方式为电池充电。充电电流可通过外部电阻编程设定，最大充电电流可达 1000mA。TP4056 有两个开漏输出状态指示端：CHRG（充电状态指示）和 STDBY（充电完成指示）。当芯片结温超过 135°C 时，内部功率管电路会自动降低充电电流。此功能使用户能够最大化利用芯片的充电能力，而无需担心芯片过热或损坏。

### 工作原理

当输入电压超过 UVLO 检测阈值且芯片使能端 CE 接高电平时，TP4056 开始为电池充电。若电池电压低于 2.9V，充电器以小电流对电池进行预充。当电池电压超过 2.9V 时，充电器进入恒流模式，充电电流由 PROG 端与 GND 端之间的电阻决定。当电池电压接近 4.2V 时，充电电流逐渐减小，TP4056 进入恒压充电模式。当充电电流降至充电终止阈值时，充电周期结束。

充电终止阈值为恒流充电电流的 1/10。当电池电压降至再充电阈值以下时，自动开始新的充电周期。芯片内部的高精度电压基准源、误差放大器和电阻分压网络确保 BAT 端调制电压精度在 1% 以内，满足锂离子和锂聚合物电池的要求。当输入电压断电或低于电池电压时，充电器进入关断模式，电池端消耗电流小于 2µA，从而延长待机时间。若使能端 CE 接低电平，充电器停止充电。

### 充电电流设置

通过 PROG 引脚与地之间的电阻设置充电电流：

```
RPROG(kΩ) = 1200 / IBAT(mA)    （误差 ±10%）
```

| RPROG (kΩ) | IBAT (mA) |
|:----------:|:---------:|
| 1.2 | 1000 |
| 2.4 | 500 |
| 3 | 400 |
| 4 | 300 |
| 6 | 200 |
| 12 | 100 |

### 充电终止

当充电电流在达到最终浮充电压后降至设定值的 1/10 时，充电周期终止。此条件通过内部滤波比较器监测 PROG 引脚来检测。当 PROG 引脚电压降至 100mV 以下且持续超过 1.8ms，充电终止，TP4056 进入待机模式，此时输入电流降至约 50µA。

充电过程中，BAT 端的瞬态负载可能导致 PROG 引脚电压在直流充电电流降至设定值 1/10 之前短暂下降到 100mV 以下。比较器的 1.8ms 延迟时间确保此类瞬态负载不会导致充电周期过早终止。一旦平均充电电流降至设定值的 1/10 以下，TP4056 终止充电周期并停止通过 BAT 端提供电流。此时，BAT 端的所有负载必须由电池供电。

### 充电状态指示

TP4056 有两个开漏状态指示输出端：CHRG 和 STDBY。充电时，CHRG 被拉至低电平，其他状态为高阻态；电池充满时，STDBY 被拉至低电平，其他状态为高阻态。未连接电池时，CHRG 闪烁指示。

| 充电状态 | CHRG | STDBY |
|:---------|:----:|:-----:|
| 充电中 | 亮 | 灭 |
| 充满 | 灭 | 亮 |
| 欠压、电池温度过高/过低、故障 | 灭 | 灭 |
| BAT 端接 1µF 电容但无电池 | 闪烁（~20Hz） | 亮 |

### 热限制

如果芯片温度超过 135°C，内部热反馈回路将降低设定充电电流。此功能可防止 TP4056 过热，允许用户提高给定电路板的功率处理能力上限，同时降低损坏风险。

### 电池温度检测

为防止电池因温度过高或过低而损坏，TP4056 内置电池温度监测电路。电池温度监测通过测量 TEMP 引脚电压实现，由电池中的 NTC 热敏电阻和电阻分压网络完成，如典型应用电路所示。若 TEMP 引脚电压低于输入电压的 45% 或高于 80%，表示电池温度过低或过高，充电暂停。TEMP 引脚直接接地则取消电池温度检测功能，其他充电功能正常。

### R1 和 R2 的关系确定

R1 和 R2 的值应根据电池的温度监测范围和热敏电阻值来确定。以下举例说明：

假设设定的电池温度范围为 TL ~ TH（TL < TH），电池使用负温度系数（NTC）热敏电阻。RTL 是其温度为 TL 时的电阻值，RTH 是其温度为 TH 时的电阻值。

在温度 TL 时，TEMP 引脚电压为：

```
VTEMPL = (R2 || RTL) / (R1 + R2 || RTL) × VIN
```

在温度 TH 时，TEMP 引脚电压为：

```
VTEMPH = (R2 || RTH) / (R1 + R2 || RTH) × VIN
```

其中：
- VTEMPH = VHIGH = K2 × VCC（K2 = 0.8）
- VTEMPL = VLOW = K1 × VCC（K1 = 0.45）

则可解得：

```
R1 = (RTL × RTH × (K2 - K1)) / (K1 × K2 × (RTH - RTL))
R2 = (RTL × RTH × (K2 - K1)) / (RTL × (K1 - K1×K2) - RTH × (K2 - K1×K2))
```

若使用正温度系数（PTC）热敏电阻，则 RTH > RTL，公式相应调整。

从上述推导可知，设定的温度范围与电源电压 VCC 无关，仅与 R1、R2、RTH、RTL 相关。RTH 和 RTL 可通过查阅电池手册或实验测试获得。

在实际应用中，如果只关注单端温度特性（如过热保护），可省略 R2，仅使用 R1。

### 欠压锁定

TP4056 内部有欠压锁定电路，用于监测输入电压，在 VCC 升至欠压锁定阈值之前保持芯片处于关断模式。当 VCC 电压升至 3.8V 时，芯片退出 UVLO 并开始正常工作。VCC 下降时的 UVLO 迟滞电压为 200mV。

### 自动充电循环

电池电压达到浮充电压且充电周期终止后，TP4056 立即监测 BAT 端电压。当 BAT 端电压低于 4.1V 时，充电周期重新开始。这确保电池保持接近满充状态，无需启动周期性充电。

### 电池反接保护

TP4056 具有锂电池反接保护功能。电池正负极反接到 TP4056 的 BAT 端时，芯片停止充电并显示故障状态，无充电电流。充电指示灯引脚为高阻态，RLED 熄灭。此时反向漏电流小于 **1mA**。正确连接电池后，TP4056 自动开始充电周期。

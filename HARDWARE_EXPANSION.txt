  ─────────────────  ────────────  ──────────────────────────────
  CH32H417 V3F       主控           信号采集、FFT、专注度、波形/频谱发送
  CH32H417 V5F       IPC从核       MI特征提取(CSP)、FFT24推理

──────────────────────────────────────────────────────────────────────────────────
2.1 蓝牙模块 — 近场直连手机
──────────────────────────────────────────────────────────────────────────────────

  候选方案: BL706 (BLE5.0 + Zigbee, 国产博流智能)
            或 CH582 (沁恒, BLE5.3, 与CH32生态一致)
  接口:     USART1 (当前未用)
  波特率:   1Mbps (BLE理论), 有效约700kbps

  用途:
    - WiFi不可用时的备用通信链路 (家庭场景, 手机直连)
    - 患者端App通过BLE接收实时波形/专注度数据
    - 低功耗待机模式, 适合长时间佩戴

  与WiFi分工:
    WiFi:  医生端远程监控 (医院/跨网段)
    BLE:   患者端本地监控 (床旁/家庭, 低延迟)

  注意事项:
    - BLE吞吐量远低于WiFi (700kbps vs 2Mbps), 需降低波形发送频率
      或只发专注度/方向结果, 不发原始波形
    - BL706/CH582需独立供电, 可由CH32H417的3.3V LDO供电

──────────────────────────────────────────────────────────────────────────────────
2.2 语音/蜂鸣器 — 本地告警输出
──────────────────────────────────────────────────────────────────────────────────

  方案A: 无源蜂鸣器 + PWM驱动
    接口:   任意GPIO + 定时器PWM输出
    成本:   <1元
    功能:   坠床警报(急促音), 久未翻身提醒(缓促音), MI训练节拍提示

  方案B: VS1053/WT588D 语音芯片
    接口:   SPI2 (当前空闲) 或 USART
    成本:   5-15元
    功能:   预录语音播报 ("请翻身", "检测到坠床", "训练开始" 等)

  推荐: 方案A用于MVP, 方案B用于产品化

──────────────────────────────────────────────────────────────────────────────────
2.3 振动马达 — 触觉反馈
──────────────────────────────────────────────────────────────────────────────────

  方案:   ERM/LRA 振动马达 + DRV2605L 驱动IC
  接口:   I2C (当前未用) + GPIO使能
  成本:   3-5元
  功能:
    - 坠床时强振动提醒陪护
    - MI训练方向提示 (左/右不同振动模式)
    - 专注度低时轻振动提醒患者

  优势: 不依赖听觉通道, 适合嘈杂环境或听力障碍患者

──────────────────────────────────────────────────────────────────────────────────
2.4 心率血氧 — 生理参数补充
──────────────────────────────────────────────────────────────────────────────────

  方案:   MAX30102 (光电容积脉搏波, 红光+红外)
  接口:   I2C
  成本:   8-12元
  功能:
    - SpO2血氧饱和度监测
    - 心率 (HR) 实时测量
    - 与专注度联合分析 (心率变异性HRV与注意力相关)

  部署: 手指夹式或耳夹式探头, 不干扰EEG电极

  注意: MAX30102功耗较高 (~50mW), 需评估电池续航影响

──────────────────────────────────────────────────────────────────────────────────
2.5 电池与电源管理 — 便携化
──────────────────────────────────────────────────────────────────────────────────

  方案:   锂电池 (103040, 1200mAh) + TP4056充电IC + DW01A保护IC
  接口:   ADC采样电池电压 (GPIO+ADC)
  成本:   15-25元 (含电池)
  功能:
    - 完全脱离USB供电, 患者可自由活动
    - 低电量提醒 (Android端弹窗)
    - 电池电压监测, 预估剩余使用时间

  续航估算:
    CH32H417双核: ~150mW
    ADS1299:      ~30mW
    WiFi模块:     ~200mW (发送时)
    ICM-42605:    ~5mW
    OLED:         ~30mW
    合计:         ~415mW
    1200mAh@3.7V = 4440mWh → 约10.7小时

  优化方向:
    - WiFi间歇发送 (非持续), 可降至 ~250mW → 约17小时
    - OLED关闭时自动休眠
    - V5F空闲时降频/休眠

──────────────────────────────────────────────────────────────────────────────────
2.6 SD卡数据日志 — 离线记录
──────────────────────────────────────────────────────────────────────────────────

  (已有SDMMC接口, 需补充软件功能)

  功能:
    - 原始EEG数据连续记录 (8通道 × 250SPS × 4字节 = 8KB/s)
    - 事件标记 (坠床/翻身/专注度突变/MI结果)
    - 离线后导出为EDF/BDF格式, 供临床分析
    - 模型权重从SD卡加载到SDRAM (已有)

  文件系统: FatFs (CH32H417已有SDMMC驱动)
  存储:     32GB SD卡可记录约46天连续数据

──────────────────────────────────────────────────────────────────────────────────
2.7 GPS定位 — 位置服务 (可选)
──────────────────────────────────────────────────────────────────────────────────

  方案:   AT6558 (中科微, 北斗+GPS双模)
  接口:   USART3 (当前未用)
  成本:   8-15元
  功能:
    - 老年患者走失定位
    - 户外康复训练轨迹记录

  注意: 室内无信号, 仅适合户外场景; 功耗约30mW

──────────────────────────────────────────────────────────────────────────────────
2.8 更大尺寸OLED/LCD — 信息展示增强
──────────────────────────────────────────────────────────────────────────────────

  方案A: 2.4寸 SPI LCD (ILI9341, 240x320)
    接口:   SPI2 (当前空闲)
    成本:   15-25元
    功能:   实时波形显示、专注度仪表盘、MI方向箭头

  方案B: 1.54寸 e-Paper (墨水屏)
    接口:   SPI2
    成本:   25-40元
    功能:   低功耗常显 (专注度数值、电量、连接状态)

  推荐: 方案A用于开发调试, 方案B用于产品化 (超低功耗)

第三部分: 接口资源汇总与分配

  接口       当前占用              可扩展
  ────────  ────────────────────  ────────────────────────
  SPI1       OLED                  -
  SPI2       空闲                  语音芯片 / LCD / 墨水屏
  SPI3       ADS1299               -
  SPI4       ICM-42605 (V2/V3)    -
  USART1     空闲                  BLE模块 (CH582/BL706)
  USART2     WiFi透传              -

  SDMMC      SD卡                  -

    P4 (可选):   振动马达 / 心率血氧 / LCD / GPS

第四部分: 通信架构 (不使用L610)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  当前: MCU → USART2 → WiFi透传模块 → TCP → Android医生端

  不使用L610 (LTE Cat.1) 的原因:
    - L610为蜂窝网络模组, 需SIM卡+流量费, 增加运营成本
    - 医院场景有WiFi覆盖, 不需要蜂窝
    - 功耗高 (~2W), 严重影响电池续航
    - 医疗设备蜂窝通信需额外认证

  远程通信替代方案:

  方案1: WiFi → 云服务器 → 医生端 (当前方案增强)
    MCU → WiFi → MQTT/HTTP → 云服务器 → 医生端App
    优势: 无额外硬件, 利用现有WiFi
    劣势: 依赖WiFi覆盖, 非实时 (延迟1-3秒)

  方案2: BLE → 手机 → 4G/5G → 云服务器 → 医生端
    MCU → BLE → 患者手机App → 云服务器 → 医生端App
    优势: 患者手机作为网关, 无需WiFi
    劣势: 依赖患者手机在线, BLE距离限制(~10m)

  方案3: WiFi + BLE 双模
    近场: BLE直连患者手机 (低延迟, 低功耗)
    远程: WiFi经路由器到云服务器 (覆盖广)
    自动切换: BLE信号弱时切WiFi, WiFi不可用时切BLE

第五部分: 产品形态设想
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  形态A: 床旁监护仪 (当前形态)
    - 固定在床头, USB供电
    - ADS1299+EEG电极帽连接患者
    - WiFi通信到医生端平板
    - 适合: 医院病房、康复中心

  形态B: 便携头戴设备 (扩展目标)
    - 集成电池、BLE、蜂鸣器
    - 干电极或半干电极 (减少准备时间)
    - 患者手机App接收数据
    - 适合: 家庭康复训练、ADHD专注力训练

  形态C: 研究平台 (开发形态)
    - 全部接口引出, 可插拔扩展板
    - SD卡日志 + LCD显示
    - 适合: 高校实验室、临床研究

第六部分: 软件适配要点
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  6.1 BLE通信适配
    - 新增 USART1 驱动 + BLE AT指令协议
    - 数据压缩: 8通道波形降采样到50SPS发送 (BLE带宽限制)
    - Android患者端新增 BLE 通信层 (替代TCP)

  6.2 蜂鸣器驱动
    - 定时器PWM输出, 频率1-4kHz
    - 告警接口: Buzzer_Alert(type) — FALL/NO_TURN/MI_CUE
    - 与ICM42605条件编译类似, 用 HAS_BUZZER 宏守卫

  6.3 SD卡日志
    - FatFs文件系统, 滚动写入
    - 文件格式: EDF+BDF (临床标准) 或自定义二进制
    - 同步标记: 坠床/翻身/专注度事件写入事件通道

  6.4 电池管理
    - ADC定时采样电池电压, 低电量阈值3.3V
    - 低电量时: 关闭OLED, 降低WiFi发送频率, 通知Android端
    - 充电状态检测 (TP4056 CHRG引脚)

   6.5 Config.h扩展
     - 新增宏: HAS_BLE, HAS_BUZZER, HAS_MAX30102, HAS_BATTERY
     - 每个BOARD_Vx块内按模块守卫
     - 保持现有条件编译架构不变

第七部分: Android 界面未来优化方向
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  7.1 脑电地形图 (Topomap)
    - 8通道数据实时映射到头皮2D热力图
    - 颜色编码: 功率/专注度/SSVEP响应强度
    - 医生端新增 TopomapFragment, 使用 Canvas 绘制
    - 需MCU端增加全通道功率发送 (当前只发2通道)

  7.2 推理结果时序图
    - 时间轴横轴, 纵轴为方向 (LEFT/RIGHT/UNCERTAIN)
    - 目标方向用虚线标注, 推理结果用实心点标注
    - 正确绿色/错误红色, 一目了然
    - 可缩放查看历史, 替代当前 RecyclerView 列表

  7.3 专注度生物反馈游戏 (患者端)
    - 专注度值控制游戏元素: 比如气球上升高度/赛车速度
    - 放松度值控制另一元素: 比如云朵飘动/背景渐变
    - 游戏化训练提升患者依从性, 适合儿童/ADHD
    - 医生端可配置游戏类型和阈值

  7.4 SSVEP频率响应热力图
    - 横轴时间, 纵轴4个目标频率, 颜色为CCA得分
    - 实时更新, 可直观看到哪个频率响应最强
    - 替代当前纯文字的得分显示
    - 需医生端新增 SpectrumHeatmapView 自定义View

  7.5 多患者同时监控 (医生端)
    - 左侧患者列表, 右侧选中患者的详细数据
    - 每个患者卡片显示: 连接状态/当前模式/最新专注度/最新推理结果
    - 需 TcpServerManager 支持多设备连接 (当前只支持1个)
    - 适合病区场景, 一名医生监控多张床位

  7.6 训练方案可视化编辑
    - 医生端拖拽式编辑训练序列: LEFT 3次 → RIGHT 3次 → 循环
    - 可保存/加载方案模板
    - 替代当前 Spinner 选择, 更灵活
    - 导出为配置文件, 不同患者使用不同方案

  7.7 数据导出为PDF报告
    - 包含: 患者信息/训练时长/推理准确率/专注度趋势图/频谱图
    - 使用 Android PdfDocument 或 iText 库
    - 替代当前纯CSV导出, 适合临床归档

  7.8 患者端语音播报 (TTS)
    - 训练指令语音提示: "请想象左手运动" / "请放松"
    - 坠床/久未翻身安全告警语音
    - 使用 Android TextToSpeech, 无需额外硬件
    - 与蜂鸣器方案互补 (2.2节), 适合嘈杂环境

  7.9 暗色/亮色主题切换
    - 医生端长时间使用护眼需求
    - 使用 Material Design 3 动态颜色
    - 患者端保持纯黑 (AR眼镜适配), 不受影响

  7.10 通道信号质量实时指示

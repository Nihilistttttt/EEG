四、功能实现
----------------------------------------

1. 电源自锁 (PD0/V_EN)
   - SystemInit() 中提前拉高 PD0 (寄存器直接操作)
   - 上电流程: SW3拨动开关 → V_EN高 → U13 LDO使能 → U11供电 → PD0自锁

2. 按键长按关机 (PD5/V_KEY)
   - 低有效 (内部上拉), 20ms消抖, 长按3000ms触发关机
   - 关机序列: 4轨关断 → PD0拉低 → U13断电 → MCU断电

3. 4路电源轨控制
   - 上电顺序: 5V → P1 → P2 → VOUT (间隔10ms)
   - 关断顺序: VOUT → P2 → P1 → 5V (逆序)
   - 5V_EN(PD3) → TPS63020 buck-boost, VSYS→5V
   - P1_EN(PC4) → EA3056 EN1, 5V→P1
   - P2_EN(PC5) → EA3056 EN2, 5V→P2
   - VOUT_EN(PC7) → SY6280 EN, 5V→5VOUT

4. I2C从机 (PC1/PC2, 地址0x20, 100kHz)
   - 与主MCU U1(CH32H417)和IMU U9(ICM-42605)共用I2C总线
   - 4.7K外部上拉电阻 R29(SCL)/R30(SDA)
   - 寄存器映射协议, 中断驱动

5. USART调试输出 (PD6, 115200 8N1, Remap2)
   - 启动日志 + 每秒状态输出

  地址  寄存器        R/W  说明

  0x00  CHIP_ID      R    0x11

  0x02  STATE        R    bit0=运行, bit1=关机中
  0x03  KEY_STATE    R    bit0=按键按下

  0x05  KEY_HOLD_H   R    按键保持时间ms高字节

  0x11  RAIL_CTRL    R/W  写bitmask控制各轨
  0x12  VEN_STATE    R    bit0=V_EN自锁状态
  0x20  CMD          W    0x01=关机 0x02=全轨开 0x03=全轨关

八、电源架构
----------------------------------------

  USB → U18(BV05C) → VBUS → U19(ETA6002充电IC) → VSYS
                                                 ↗ BAT(H3电池接口)
  VSYS → SW3(拨动开关) → V_EN(PD0) → U13(TPS7A2033 LDO) → 3.3V → U11 VDD
  VSYS → U20(TPS63020, EN=PD3) → 5V → U4(EA3056, EN1=PC4, EN2=PC5) → P1/P2
                                    → U21(SY6280, EN=PC7) → 5VOUT

  I2C总线: U11(PC1/PC2) ↔ FPC1 ↔ FPC2 ↔ U1(CH32H417) + U9(ICM-42605)

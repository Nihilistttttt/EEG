第二部分: 8通道映射 (关键常量)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ADS1299物理引脚 → ch_data索引 (硬件层):
  CH0=C4(0), CH1=F4(1), CH2=CP4(2), CH3=OZ(3),
  CH4=O1(4), CH5=CP3(5), CH6=C3(6), CH7=F3(7)
  注意: F4/C4物理通道已交换 (C4用好的ch0, F4用有噪声的ch1)

ch_data索引 → raw_vals逻辑索引 (软件层):
  raw_vals[0]=OZ, [1]=O1, [2]=F3, [3]=F4,
  [4]=CP3, [5]=CP4, [6]=C3, [7]=C4

Android EegChannels常量 (与raw_vals索引一致):
  CH_OZ=0, CH_O1=1, CH_F3=2, CH_F4=3,
  CH_CP3=4, CH_CP4=5, CH_C3=6, CH_C4=7

V5F MI通道映射:
  g_v5f_ch_map[4] = {5, 2, 6, 0} → CP3, CP4, C3, C4
  Laplacian: left=CP3-C3, right=CP4-C4

专注度5通道加权:
  W_F3=0.28, W_CP3=0.22, W_CP4=0.22, W_C3=0.14, W_C4=0.14
  W_OZ=0.00, W_O1=0.00, W_F4=0.00

3.2 V3F/Hardware/ — 硬件驱动与信号处理主循环
────────────────────────────────────────────────────────────────────────────────

ADS1299.c / ADS1299.h
  ADS1299 8通道EEG ADC驱动。
  通过SPI3+DMA双缓冲采集27字节帧数据，DRDY下降沿触发DMA读取，
  环形缓冲区存储。
  关键函数: ADS1299_Init(), ADS1299_ParseRawFrame(), ADS1299_CodeToVolt(),
            ring_buffer_get_frame()
  通道映射: ADS1299_EEG_CH_C4=0, CH_F4=1, CH_CP4=2, CH_OZ=3,
            CH_O1=4, CH_CP3=5, CH_C3=6, CH_F3=7
  常量: ADS1299_VREF_DEFAULT=4.5V, ADS1299_GAIN_DEFAULT=24

ICM42605.c / ICM42605.h
  ICM-42605六轴IMU驱动。SPI4通信，100Hz采样，
  含陀螺仪零偏校准、角速度积分、温度补偿低通滤波、角度计算。
  关键函数: ICM42605_BCI_Init(), ICM42605_Task(), ICM42605_GetAngleDeg10()

Serial.c / Serial.h
  双串口驱动(DEBUG=USART1, WiFi=USART2)，921600bps。
  TX环形缓冲区(8192字节)，RX IDLE中断+DMA接收。
  关键函数: Serial_Init(), Serial_Printf(), Serial_SendArray_DMA(),
            Serial_IsDataReady(), Serial_GetDataPacket()

Signal_Analysis.c / Signal_Analysis.h
  ★核心信号处理主循环★
  主循环流程:
    1. 从ADS1299环形缓冲区取帧
    2. 解析8通道原始数据 → raw_vals[8]
    3. 基线去除 → baseline_vals[8]
    4. 实时去漂移 → drift_vals[8]
    5. 50Hz陷波 → ab_pre_vals[8]
    6. 带通滤波(2-40Hz) → filt_vals[8]
       - OZ/O1按需计算(由DisplayConfig_NeedsBandpass决定)
       - ch2-ch7始终计算
    7. 按DISPLAY_CFG发送波形(跳过WAVE_TYPE_NONE)
    8. 填充FFT环形缓冲区
    9. 触发FFT流水线(每STEP_SIZE=125个采样)
   10. 处理串口命令(Parse_CommandEx)
   11. ICM42605_Task()处理IMU数据
   12. 姿态监测和患者监护
   13. 双核IPC帧共享(每1帧通知V5F)
  关键全局变量: g_eeg_app_mode, g_ipc_diag_enable, g_posture_diag_enable

Config.c / Config.h
  外设时钟使能函数 + ★全局硬件引脚配置★
  集中定义所有引脚编码、AF映射、DMA通道、中断号、波特率等。
  关键常量: SERIAL_DEBUG_BAUDRATE=921600, SERIAL_WIFI_BAUDRATE=921600,
            SERIAL_WIFI_TX_RING_SIZE=8192

OLED.c / OLED.h / OLED_Font.h
  OLED显示驱动(SPI/I2C双接口)，含频谱柱状图和波形折线绘制。

Timer_1ms.c / Timer_1ms.h
  TIM2 1ms定时中断，驱动ICM42605采样节拍。

patient_monitor.c / patient_monitor.h
  患者监护算法。基于IMU姿态数据检测翻身、坠床和久卧不动，
  含状态机驱动的坠床确认和冷却逻辑。

posture_detect.c / posture_detect.h
  姿态检测算法。对加速度低通滤波后按重力方向分类:
  仰卧/俯卧/左侧/右侧/坐姿，带稳定确认延时。

Direction_Classifier.c / Direction_Classifier.h
  方向分类器。SVM/LDA/MLP三种分类器，24维特征标准化后输出LEFT/RIGHT。

Direction_Model.c / Direction_Model.h
  方向推理模型封装层，将分类器结果转为Direction_t枚举。

Direction_Model_Weights.h
  10维MLP占位权重(全零)。

Direction_Model_4ch_Weights.h
  24维4通道方向模型实际训练权重(由train_direction_24d.py生成)。

Direction_Model_10feat_Weights.h
  10维特征方向模型权重(由train_current_10feat.py生成)。

Signal_Analysis_current_10feat_integration_snippet.c
  非编译文件，集成示例代码片段。

3.3 V3F/EEG_FFT/ — FFT与频谱分析
────────────────────────────────────────────────────────────────────────────────

eeg_fft.c / eeg_fft.h
  ★FFT流水线主逻辑★
  分步状态机执行(Process_FFT_Step每帧调用一次):
    FFT_STEP_START
    → FFT_STEP_EXTRACT_RAW_FRAME (提取原始帧起始位置)
    → FFT_STEP_SPECTRUM_RAW (设置FFT参数,fft_pair_index按需跳过)
    → FFT_STEP_FFT_COPY_INPUT (Hanning窗+去均值去线性趋势)
    → FFT_STEP_FFT_TRANSFORM (复数FFT变换)
    → FFT_STEP_FFT_MAGS (提取幅度谱,4对通道循环)
    → FFT_STEP_SEND_RAW_SPECTRUM (发送原始频谱,去重)
    → FFT_STEP_FREQ_FILTER (频域滤波:DC窗+50Hz陷波+HF截止)
    → FFT_STEP_SEND_FREQ_SPECTRUM (发送频域滤波频谱,去重)
    → FFT_STEP_EXTRACT_FILT_FRAME (提取滤波帧起始位置)
    → FFT_STEP_SPECTRUM_FILT (设置滤波FFT参数)
    → FFT_STEP_FFT_COPY_INPUT/TRANSFORM/MAGS (第二次FFT)
    → FFT_STEP_BAND_POWER (计算8通道delta/theta/alpha/beta功率)
    → FFT_STEP_ATTENTION (5通道加权专注度计算+EMA平滑)
    → FFT_STEP_SEND_FOCUS (发送专注度数据)
    → FFT_STEP_SEND_FILT_SPECTRUM (发送时域滤波频谱,去重)
    → FFT_STEP_UPDATE_TREND (趋势窗口更新)
    → FFT_STEP_JUDGE_STATE (瞬时/趋势状态判定)
    → FFT_STEP_FINISH

  关键常量: FFT_SIZE=256, SAMPLE_RATE=250Hz, STEP_SIZE=125,
            NUM_CHANNELS=8
  专注度权重: W_F3=0.28, W_CP3=0.22, W_CP4=0.22, W_C3=0.14, W_C4=0.14
  频谱发送去重: 同一通道+同一类型只发送一次

3.5 V3F/EEG_Protocol/ — 命令解析协议
────────────────────────────────────────────────────────────────────────────────

eeg_cmd_parser.c / eeg_cmd_parser.h
  EEG串口命令解析器。支持以下命令:
  - MODE,TRAIN / MODE,TEST — 设置训练/测试模式
  - MODE,SET,n — 设置应用模式(1=COLLECT, 2=INFER, 3=CSP)
  - TRIAL,LEFT / TRIAL,RIGHT — 开始试次
  - STOP — 停止
  - STATUS — 查询状态
  - MODEL,SET,AUTO/FFT24/CSP — 设置推理模型
  - MODEL,GET — 查询当前模型

  - IPCDIAG,ON/OFF — IPC诊断开关
  - POSTURE,ON/OFF — 姿态诊断开关
  - ACK,seq — 确认收到(停止重传)
  含ACK重传机制(Retry_Tick, 300ms超时, 最多10次)。

3.6 V3F/Protocol/ — 二进制帧协议
────────────────────────────────────────────────────────────────────────────────

Message_Parser.c / Message_Parser.h
  二进制帧协议解析与打包。HDLC式帧格式:
  - 帧定界: 0x7E
  - 转义: 0x7D, 异或0x20
  - 命令码: CMD_RAW_WAVE=0x04, CMD_FILT_WAVE=0x10, CMD_BASELINE_WAVE=0x11,
            CMD_FOCUS=0x05,
            CMD_RAW_SPECTRUM_CH0~7=0x20~0x27,
            CMD_FREQ_SPECTRUM_CH0~7=0x30~0x37,
            CMD_FILT_SPECTRUM_CH0~7=0x40~0x47

  波形帧: 5字节 (1字节通道号 + 4字节float值)
  频谱帧: 分32个片段发送，每片16字节(4个float)
  专注度帧: 18字节 (4xfloat attn0/attn1/ema0/ema1 + 1byte trend + 1byte instant)

  DisplayConfig_t: 4通道紧凑格式
    wave_ch[4], wave_type[4], spec_type[4]
    WAVE_TYPE_NONE=0xFF, SPEC_TYPE_NONE=0xFF

  按需计算函数:
    DisplayConfig_NeedsBandpass(ch) — 通道ch是否需要带通滤波
    DisplayConfig_NeedsRawFFT(ch) — 通道ch是否需要原始FFT
    DisplayConfig_NeedsFiltFFT(ch) — 通道ch是否需要滤波FFT
    DisplayConfig_IsAllNone() — 是否所有slot都是NONE

9.1 脑电信号采集链路
────────────────────────────────────────────────────────────────────────────────

ADS1299 (250Hz采样)
  │ SPI3+DMA双缓冲, 27字节/帧 (3字节状态+8x3字节通道数据)
  ↓
ring_buffer (V3F)
  │ ring_buffer_get_frame()
  ↓
ADS1299_ParseRawFrame() → ch_data[8] (24bit有符号)
  │ ADS1299_CodeToVolt() → raw_vals[8] (float, μV)
  ↓
Signal_Analysis主循环:
  ├─ baseline_vals[8] = Waveform_RemoveDisplayBaseline_8CH(raw_vals)
  ├─ drift_vals[8] = EEG_RemoveRealtimeDrift(raw_vals)
  ├─ ab_pre_vals[8] = IIR_SOS_Step(drift_vals, notch)  // 50Hz陷波
  ├─ filt_vals[8] = IIR_SOS_Step(ab_pre_vals, bandpass) // 2-40Hz带通
  │   (OZ/O1按需计算, ch2-ch7始终计算)
  ├─ 按DISPLAY_CFG发送波形 → Send_WaveformSingle() → USART2
  ├─ 填充RingBuf/RingBufFiltered → FFT流水线
  └─ 双核IPC → V5F

9.2 FFT频谱分析链路
────────────────────────────────────────────────────────────────────────────────

RingBuf (去漂移+陷波后) / RingBufFiltered (带通滤波后)
  │ STEP_SIZE=125个采样触发一次
  ↓
Process_FFT_Step() 分步状态机:
  1. 提取原始帧 → Hanning窗 + 去均值去线性趋势
  2. 复数FFT (256点, 2通道配对)
  3. 提取幅度谱 → 8通道
  4. 发送原始频谱(按DISPLAY_CFG, 去重)
  5. 频域滤波(DC窗+50Hz陷波+HF截止)
  6. 发送频域滤波频谱(按DISPLAY_CFG, 去重)
  7. 提取滤波帧 → 第二次FFT
  8. 发送时域滤波频谱(按DISPLAY_CFG, 去重)
  9. 计算8通道频带功率(delta/theta/alpha/beta)
  10. 5通道加权专注度计算 + EMA平滑
  11. 发送专注度数据
  12. 趋势/瞬时状态判定

9.3 双核IPC数据链路
────────────────────────────────────────────────────────────────────────────────

V3F → V5F (每1帧ADS1299数据):
  DualCore_IPC_SendFrameFromV3F(frame_buf, 27)
  │ IPC_CH0中断
  ↓
V5F IPC_CH0_Handler():
  1. 校验帧数据
  2. 提取4通道(CP3/CP4/C3/C4)数据
  3. 去漂移 + 陷波 + 带通滤波
  4. 填充4通道环形缓冲区
  5. 每DUALCORE_V5F_WINDOW_SIZE=125采样:
     - FFT特征提取(24维) 或 CSP特征提取
     - SVM/LDA推理
     - EMA结果融合
  6. ACK回传: 预处理结果 + 特征 + 推理结果
  ↓
V3F接收ACK → 更新全局变量 → Signal_Analysis读取

9.4 WiFi通信数据链路
────────────────────────────────────────────────────────────────────────────────

MCU USART2 (921600bps) ←→ WiFi模块 ←→ TCP

  MCU → Android (二进制帧, HDLC格式):
    波形帧: [0x7E][cmd][ch][float4B][0x7E]
    频谱帧: [0x7E][cmd][frag_idx][total_frags][float×4]×32片[0x7E]
    专注度帧: [0x7E][0x05][attn0×4][attn1×4][ema0×4][ema1×4][trend][instant][0x7E]

  MCU → Android/Python (文本行, \r\n结尾):
    RESULT,seq=,src=,window=,INTENT=LEFT/RIGHT,S_LEFT=,S_RIGHT=,CONF=,MODEL=
    TASK,LEFT/RIGHT,start/done
    READY_TRAIN / READY_TEST
    MODE_SET_OK,n
    DISPLAY_CFG_OK,12参数
    IPCDIAG,ack=,notify=,ok=,bad=,v5fhb=
    POSTURE,姿态名,gx=,gy=,gz=,conf=,stable=
    MODE_DIAG,app=,work=,paused=
    V5F_DIAG/RAW,valid=,cnt=,pred=

  Android → MCU (文本行):
    DISPLAY_CFG,12参数
    MODE,TRAIN / MODE,TEST / MODE,SET,n
    TRIAL,LEFT / TRIAL,RIGHT
    STOP
    MODEL,SET,AUTO/FFT24/CSP
    ACK,seq
    IPCDIAG,ON/OFF
    POSTURE,ON/OFF
    WIFI_ADD,ssid,pwd / WIFI_DEL,ssid

  Android医生端 → Android患者端 (TCP:41006文本行):
    PAGE,n (页面切换通知)
    SSVEP,START,freqHz (SSVEP刺激开始)
    SSVEP,STOP (SSVEP刺激停止)
    SSVEP,RESULT,freq,ratio,score (SSVEP识别结果)
    TASK,LEFT/RIGHT,start/done (MI试次)
    RESULT,INTENT=LEFT/RIGHT (推理结果)

9.5 DISPLAY_CFG页面感知机制
────────────────────────────────────────────────────────────────────────────────

需要波形的页面 (onResume发送各自DISPLAY_CFG):
  MonitorFragment    → 2通道波形+频谱, slot2-3=NONE
  WaveCompareFragment → 4路波形, 频谱全NONE
  SpectrumCompareFragment → 4路频谱, 波形=RAW
  SsvepTrainingFragment → O1滤波波形+O1原始频谱+O1时域滤波频谱

不需要波形的页面 (onResume发送全NONE DISPLAY_CFG):
  FocusHistoryFragment, MiTrainingFragment, InferenceFragment,
  PostureFragment, ConfigFragment

安全策略:
  ① onCreateView中绝不发送DISPLAY_CFG
  ② 只在onResume发送
  ③ 不需要波形的页面发送全NONE, MCU停止波形/频谱发送(节省带宽)
  ④ FFT/专注度/MI训练等后台计算不受影响

10.1 硬件准备
────────────────────────────────────────────────────────────────────────────────

1. 烧录V3F固件 (EXAM/GPIO/EEG/V3F/)
   - 配置: V3F=100MHz, USART1=921600(DEBUG), USART2=921600(WiFi)
   - SPI3连接ADS1299, SPI4连接ICM42605

2. 烧录V5F固件 (EXAM/GPIO/EEG/V5F/)
   - 配置: V5F=400MHz, 等待IPC中断

3. ADS1299连接8通道EEG电极:
   CH0=C4, CH1=F4, CH2=CP4, CH3=OZ, CH4=O1, CH5=CP3, CH6=C3, CH7=F3

4. WiFi模块连接USART2, 配置为AP模式或STA模式

5. ICM42605连接SPI4, 安装在患者胸部/腰部

10.2 软件启动流程
────────────────────────────────────────────────────────────────────────────────

1. MCU上电:
   a. V3F main() → SystemInit() → Serial_Init() → ICM42605_BCI_Init()
      → ADS1299_Init() → EEG_FFT_Init() → DisplayConfig_SetDefaults()
      → Signal_Analysis_Start() 主循环
   b. V5F main() → 释放HSEM → IPC_CH0中断初始化 → 空循环等待
   c. V3F主循环: 采集→滤波→FFT→专注度→波形/频谱发送→命令解析→IMU→姿态

2. Android医生端启动:
   a. SplashActivity → HomeActivity (9张卡片)
   b. TcpServerManager.start() 启动所有TCP/UDP监听
   c. 等待MCU WiFi模块连接TCP:41002
   d. 收到"HELLO,DEVICE" → 设备已连接
   e. 点击卡片 → MainActivity → ViewPager2 → 各Fragment

3. Android患者端启动:
   a. DoctorConnector.startAutoConnect() 搜索医生端
   b. 连接TCP:41004/41005/41006
   c. 收到"HELLO,PATIENT" → 患者已连接

10.3 脑电监测流程
────────────────────────────────────────────────────────────────────────────────

1. 医生端点击"脑电监测" → MonitorFragment
2. onResume → sendDisplayConfig() → MCU开始发送配置的波形+频谱
3. MCU: 每帧采样 → 按DISPLAY_CFG发送波形(5字节/通道)
4. MCU: 每125采样 → FFT流水线 → 发送频谱(32片×20字节) + 专注度(18字节)
5. Android: FrameParser解析 → DataDispatcher → MonitorFragment.onWaveData/onSpectrumData
6. WaveformView/SpectrumView实时绘制

10.4 专注度监测流程
────────────────────────────────────────────────────────────────────────────────

1. 医生端切换到"专注度"页 → FocusHistoryFragment
2. onResume → 发送全NONE DISPLAY_CFG → MCU停止波形/频谱发送
3. MCU: FFT仍运行 → 专注度数据仍发送(CMD_FOCUS)
4. Android: onFocusData → FocusHistoryStore → FocusChartView绘制

10.5 SSVEP训练流程
────────────────────────────────────────────────────────────────────────────────

1. 医生端切换到"SSVEP训练"页 → SsvepTrainingFragment
2. onResume → sendDisplayConfig(O1滤波波形+频谱) → MCU发送O1数据
3. 医生选择目标频率(11/13/15/17Hz)
4. 点击"开始训练" → CommandSender.ssvepStart() → MCU
5. 同时通过41006发送"SSVEP,START,freqHz"给患者端
6. 患者端SsvepStimulusView开始vsync精确闪烁
7. 患者端首帧回调 → "SSVEP,STIMULUS_STARTED" → 医生端
8. 医生端SsvepAnalysisManager开始收集O1波形样本
9. 窗口满后FBCCA分析 → SsvepResult → 显示结果
10. 结果通过41006转发给患者端
11. 进度条满后清空重来，进入下一次分析

10.6 MI训练流程
────────────────────────────────────────────────────────────────────────────────

1. 医生端切换到"MI训练"页 → MiTrainingFragment
2. onResume → 发送全NONE DISPLAY_CFG → MCU停止波形/频谱发送
3. 点击"开始训练" → CommandSender.setMode(COLLECT) + startTraining()
4. MCU进入训练模式 → 回复READY_TRAIN
5. 医生端状态机: REST(5秒) → TRIAL(25秒) → REST → TRIAL...
6. 每个试次: CommandSender.trialLeft/Right() → MCU
7. MCU: TASK,LEFT,start → 采集CSP数据 → TASK,LEFT,done
8. 同时通过41006转发TASK命令给患者端 → 显示方向箭头
9. 训练完成 → CommandSender.startTest() → MCU进入推理模式
10. MCU: V5F推理 → RESULT,INTENT=LEFT/RIGHT → 医生端+患者端

10.7 方向推理流程
────────────────────────────────────────────────────────────────────────────────

1. 医生端切换到"方向识别"页 → InferenceFragment
2. onResume → 发送全NONE DISPLAY_CFG
3. 如果MCU已在推理模式 → 实时接收RESULT
4. MCU: V5F每125采样推理一次 → 4行投票 → RESULT
5. Android: onInferenceResult → 显示方向/置信度
6. 可验证结果(正确/错误) → InferenceRecordStore持久化
7. 可导出CSV

10.8 姿态监护流程
────────────────────────────────────────────────────────────────────────────────

1. 医生端切换到"姿态监护"页 → PostureFragment
2. onResume → 发送全NONE DISPLAY_CFG
3. MCU: ICM42605_Task()每帧更新 → Posture_FeedAccel()
4. 姿态分类 → POSTURE文本行 → Android
5. 患者监护: 翻身/坠床/久卧检测 → 事件上报
6. Android: onPostureState/onTurnEvent/onFallEvent → 显示

10.9 Python上位机SSVEP流程
────────────────────────────────────────────────────────────────────────────────

1. 运行SSVEP.py
2. 自动发现网关 → 连接TCP:41003
3. pygame窗口显示闪烁刺激(240Hz vsync)
4. 接收MCU原始数据 → FrameParser解析 → 提取O1通道
5. FBCCA分析 → 识别目标频率 → 显示结果

13.1 DISPLAY_CFG命令格式
────────────────────────────────────────────────────────────────────────────────

  DISPLAY_CFG,wave_ch0,wave_type0,wave_ch1,wave_type1,spec_type0,spec_type1,
              wave_ch2,wave_type2,wave_ch3,wave_type3,spec_type2,spec_type3

  wave_type: 0=RAW, 1=FILT, 2=BASELINE, 0xFF=NONE
  spec_type: 0=RAW, 1=FREQ_FILTER, 2=TIME_FILTER, 0xFF=NONE
  wave_ch:   0=OZ, 1=O1, 2=F3, 3=F4, 4=CP3, 5=CP4, 6=C3, 7=C4

13.2 RESULT命令格式
────────────────────────────────────────────────────────────────────────────────

  RESULT,seq=N,src=V5F,window=N,dt_ms=2000,win_rows=4,
         INTENT=LEFT/RIGHT,S_LEFT=N,S_RIGHT=N,CONF=N,trained=0/1,MODEL=FFT24/CSP

13.3 二进制帧格式 (HDLC)
────────────────────────────────────────────────────────────────────────────────

  [0x7E][cmd_byte][payload...][0x7E]
  转义: payload中0x7E→0x7D 0x5E, 0x7D→0x7D 0x5D
  波形payload: [ch(1B)][float_value(4B)] = 5字节
  频谱payload: [frag_idx(1B)][total_frags(1B)][float×4] = 18字节/片, 32片
  专注度payload: [attn0(4B)][attn1(4B)][ema0(4B)][ema1(4B)][trend(1B)][instant(1B)] = 18字节

# 3描述

UCC12040是一款DC/DC电源模块，具有3 kvrms基本隔离额定值，旨在为需要具有良好调节输出电压的偏置电源的隔离电路提供高效，隔离的电源。该器件集成了变压器和具有专有架构的DC/DC控制器，可提供$5 0 0 \ \m {\m W}$（典型）的低EMI隔离功率。

UCC12040集成了保护功能，提高了系统的稳健性。该器件还具有使能引脚，同步能力和调节5-V或3.3 v输出选项。UCC12040是一款低调、小型化的解决方案，采用宽体SOIC封装，售价2美元。6 5 \mathsf {-} \mathsf {m m}$高度。

7.1概述

UCC12040器件集成了一个高效、低排放的隔离DC/DC转换器。这种方法通常在3000VRMS的基本隔离屏障上提供$5 00 \mathsf {m} \mathsf {W}$干净、稳定的功率。

集成的DC/DC转换器采用开关模式操作和专有电路技术，以减少功率损耗和提高效率。专门的控制机制，时钟方案，并使用片上变压器提供高效率和低辐射发射。

VINP电源提供给主电源控制器，用于切换连接到集成变压器的功率级。功率被转移到二次侧，整流，并调节到由SEL引脚条件设定的水平。

快速反馈控制回路监控VISO和输出负载，并确保在负载瞬态期间低过调和欠调。带有迟滞的欠压闭锁（UVLO）集成在VINP电源上，确保了系统在噪声条件下的稳健性能。

UCC12040适用于电路板空间有限，需要更多集成的应用。这些设备也适用于非常高的电压应用，其中满足所需隔离规格的电力变压器体积庞大且昂贵。

# 7.3特性描述

# 7.3.1启用和禁用

强制enlow关闭设备，大大降低了VINP的功耗。将EN引脚拉高以启用正常的设备功能。EN引脚有一个弱的内部下拉电阻，所以如果引脚打开，设备会浮到禁用状态。

# 7.3.2 UVLO，上电和下电行为

UCC12040在VINP电源上有UVLO（欠压锁定）。上电后，当VINP电压低于阈值电压VUVPR时，初级侧变压器驱动器被禁用，VISO输出断开。一旦达到阈值，输出就会上电。同样，如果VINP低于VUVPF，则转换器将被禁用，并且在VISO处没有输出。两个UVLO阈值电压都有滞回以避免抖振。

# 7.3.4热关闭

热保护也集成，以帮助防止设备在过载和短路条件下的隔离输出损坏。在这种情况下，器件温度开始升高。当硅结温${\科幻T} _ {\ mathrm {j}}感觉到美元主面死亡超过阈值$ {\ mathsf {T S D  } } _ { { \ mathsf {T H R}}} $(典型的1美元6 5 ^{\保监会}\ mathrm {C}),美元热关闭激活和主控制器关闭它消除了能源供应美元\ mathsf {V} _ {1 \ mathsf{年代}\ mathsf {O}} $负荷,导致设备降温。当结温从关断点下降约$ 2.7 ^ {\circ} \mathsf {C}$ （TSDHYST）时，器件开始正常工作。如果出现过载或输出短路情况，则重复此保护循环。确保设计防止器件结温达到如此高的值。

# 7.3.5外部时钟与同步

# 7.3.7电磁兼容性注意事项

# 9电源建议

UCC12040的推荐输入电源电压（VINP）在$4之间。5 \: $ $和$ $5。5 \lor。为了确保可靠运行，必须尽可能靠近电源引脚放置足够的去耦电容器。在输入端的VINP和GNDP引脚之间以及隔离输出端的VISO和GNDS之间放置本地旁路电容器。推荐使用低ESR的陶瓷表面贴装电容器。进一步建议放置两个这样的电容器：一个值为$ 10 ~ \mu \mathsf {F}$的电容器用于电源旁路，另一个并联的100-nF电容器用于高频滤波。输入电源必须具有适当的额定电流，以支持终端应用所需的输出负载。

# 10 Layout

# 10.1布局指南

UCC12040集成隔离电源解决方案简化了系统设计，减少了电路板面积的使用。为了实现最佳性能，适当的PCB布局非常重要。以下是一些建议：

1. 将去耦电容放置在尽可能靠近器件引脚的地方。对于输入电源，将电容放置在引脚3 （VINP）和引脚2 （GNDP）之间。对于隔离输出电源，将电容放置在引脚14 （VISO）和引脚15 （GNDS）之间。这个位置对输入去耦电容特别重要，因为该电容提供与功率驱动电路的快速开关波形相关的瞬态电流。
2. 由于器件没有用于散热的热垫，因此器件通过各自的GND引脚散热。确保所有GNDP和GNDS引脚上都有足够的铜（最好是连接到接地平面），以获得最佳散热效果。
3. 如果空间和层数允许，建议将VINP、GNDP、VISO和GNDS引脚通过多个适当尺寸的过孔连接到内部地或电源平面。或者，尽可能广泛地追踪这些网，以尽量减少损失。
4. TI还建议将无连接引脚（NC）接地到各自的接平面上。对于引脚6,7和8，连接到GNDP。对于引脚10、11和12，连接到GNDS。这将允许更连续的地平面和更大的热沉质量。
5. 建议至少使用四层来完成低emi PCB设计。内层可以比外层间隔更近，用于在GNDP和GNDS之间创建高频旁路电容器，以减少辐射发射。确保适当的间隔（层间和层对层），以避免降低隔离能力。这些间距将根据印刷电路板结构参数而变化，例如介电材料和厚度。
6. 注意PCB板外层主接地平面（GNDP）和次接地平面（GNDS）之间的间距。当两接地平面的间距小于设备封装平面的间距时，可以减小系统的有效漏电和/或间隙。
7. 为确保主次侧之间的隔离性能，请避免在UCC12040器件下方的外铜层上放置任何PCB走线或铜。
